Title: Unauthorized Database Operation Vulnerability in Ludashi Watermark Removal Management System#

BUG_Author: liuhanzhi

Affected Version: Watermark removal management system ≤ 4.0

Vendor: Standalone Watermark Removal Mini Program

Software: Ludashi Watermark Removal Management System Download Link

Vulnerability Files:

  • admin/ajax.php

Description:#

  1. Unauthorized database write operations:

    • Deobfuscate the obfuscated code in /admin/ajax.php, click to download the anti-obfuscation code.

    • In /admin/ajax.php, the interface dispatches a large amount of add/delete/update logic through the act parameter.

    • No effective backend session authentication and authorization logic is found in the file, so attackers can directly invoke sensitive operations without logging in.

  2. Cause of the vulnerability:

    • The interface directly trusts the request source and does not verify administrator login status before each write-operation branch.
    • The interface exposes add/delete/update capabilities (INSERT/UPDATE/DELETE) for multiple business tables.

  3. act parameters that can be called without authorization:

    • Add: edit_faqtj, edit_bantj, edit_tooltj, edit_dytj, edit_Xcxtj
    • Modify: edit_Wzxx, edit_lds, edit_Adpass, edit_Xcxxg, edit_faqxg, edit_banxg, edit_toolxg, edit_dyxg, edit_adxg
    • Delete: edit_XcxShanchu, edit_faqShanchu, edit_toolShanchu, edit_banShanchu, edit_dyShanchu

  4. Impact:

    • Unauthorized addition/tampering/deletion of backend data such as tutorials, FAQ, carousels, and tools.
    • Site configuration and ad configuration can be modified, and administrator passwords can be changed.
    • Causes business data damage, backend takeover, and persistent operational risk.

  5. There are many public Internet deployment cases.

Local Verification#

  1. Download the official source code.

  2. Go to /去水印小程序/去水印4.0新版本/, extract 最新版去水印4.0版本后端安装源码.zip, and copy all extracted backend code to a test directory.

  3. Add a docker-compose.yml file in the test directory.

services:
  web:
    image: php:7.2-apache
    container_name: test-vul-web
    platform: linux/amd64
    ports:
      - "8889:80"
    volumes:
      - ./:/var/www/html
    depends_on:
      - db
    command: >
      bash -lc "
      docker-php-ext-install pdo pdo_mysql mysqli &&
      a2enmod rewrite &&
      apache2-foreground
      "

  db:
    image: mysql:5.6
    container_name: test-vul-mysql
    platform: linux/amd64
    ports:
      - "3308:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: ludeqi
      TZ: Asia/Shanghai
    command: ["mysqld", "--character-set-server=utf8", "--collation-server=utf8_general_ci"]
    volumes:
      - db_data:/var/lib/mysql

volumes:
  db_data:
  1. Start the Docker containers.
docker compose -p test-vul up -d
  1. After successful startup, visit http://127.0.0.1:8889/install for initialization (wait a while and refresh to see the initialization page).

  1. Visit http://127.0.0.1:8889/admin/login.php and log in with admin:123456:111111 to access the backend.
